# PUNCH ’N’ GO

- Начинай с [указателя проекта](docs/README.md). В нём есть текущий этап, статусы, открытые вопросы и ссылки по подсистемам.
- Для целевого поведения читай [GDD](docs/GDD.md), для текущего кода и проектных контрактов — [техническую спецификацию](docs/TECH_SPEC.md) и соответствующие модули. Верифицируй фактическую реализацию на текущем коммите.
- Параметры и кандидаты контента собраны в [балансе](docs/BALANCE.md), ожидаемые результаты — в [приёмке](docs/ACCEPTANCE.md).
- Сохраняй идентификаторы INV, O и TC и исходные статусы при переносе материала. Спорное поведение фиксируй как открытый вопрос. При изменении игрового поведения обновляй связанные материалы в том же PR.
- Боевой репозиторий и UX-демо map_2 используют разные данные. Описание границы есть в [технической спецификации](docs/TECH_SPEC.md#ux-boundary).
- Команды запуска и проверок: [README](README.md).
