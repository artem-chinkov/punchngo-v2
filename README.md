# PUNCH ’N’ GO — Park Run v2.0

Портретный файтинг от первого лица. Один полный забег по парку: непрерывный бег, три полосы, цепные столкновения, временные улучшения и финал с Бульдогом.

[Играть в браузере на GitHub Pages](https://artem-chinkov.github.io/punchngo-v2/)

## Запуск на Mac

Нужен Node.js 22.12+ с npm. В каталоге `punchngo-v2`:

```sh
npm ci
npm run dev -- --port 5175
```

Открой [http://localhost:5175/](http://localhost:5175/). Тап — прямой удар и рывок, удержание — серия прямых ударов с одним начальным рывком. Свайп вверх — хук, вниз — апперкот, влево или вправо — переход на соседнюю полосу с боковым ударом. Удержание продолжает бить на красном и жёлтом сигналах; для контрудара отпусти палец и тапни отдельно на жёлтом. На первом запуске оба этапа обучения показываются поверх игры. Кнопка «Обучение» повторяет их без сброса рекордов.

Бульдог появляется на 2:20 игрового времени. Паузы обучения и выбора улучшений в это время не входят. В меню и на экране результата есть отдельные настройки музыки и эффектов; значок динамика в HUD отключает весь звук. Настройки сохраняются в этом браузере.

## Проверка сборки и запуск на iPhone

```sh
npm test
npm run build
npm run preview -- --host 0.0.0.0 --port 5175
```

Mac и iPhone должны быть в одной Wi‑Fi сети. Открой в Safari на iPhone адрес из строки `Network` в Терминале и держи телефон вертикально. Для запуска с живым обновлением вместо preview используй `npm run dev -- --host 0.0.0.0 --port 5175`.

- `?debug=1` показывает DEV. В нём доступны баланс, seed, скорость времени, неуязвимость, XP, выдача улучшений, фазы Бульдога, зоны и FPS, просмотр анимаций и сброс обучения. Параметры новых ударов находятся в разделе «Спецприёмы и удержание». В DEV → «Камера» высота (0–120%, по умолчанию 0%) и горизонт (по умолчанию 50%) меняются сразу на остановленном кадре.
- `?seed=7` закрепляет последовательность построений и карточек для повторяемого теста.
- `?renderer=auto` включает выбор Phaser AUTO. Canvas используется по умолчанию.
- `?assets=raster` включает PNG/атласы из [реестра](src/assets/rasterPack.ts). Для отсутствующих кадров игра использует процедурную графику. Подключай файлы из `public/assets/` с идентификаторами из [ids.ts](src/assets/ids.ts) и сохраняй точки опоры кадров.
